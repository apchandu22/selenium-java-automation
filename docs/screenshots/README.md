# Test Evidence / Screenshots

This folder is reserved for screenshots and other visual evidence captured during actual test execution.

## Recommended Evidence

- Application home page
- Product details page
- Add-to-cart result
- Cart validation
- Checkout flow
- Successful TestNG execution
- Failed-test screenshot, when a test actually fails
- Extent Report summary
- GitHub Actions workflow result

## Naming Convention

Use a consistent naming convention such as:

```text
<test-id>_<short-description>.png
```

Examples:

```text
TC-001_storefront-loaded.png
TC-012_product-added-to-cart.png
TC-019_product-removed-from-cart.png
```

## Evidence Policy

Screenshots should represent actual test execution. Do not upload fabricated test results, fake defects, or screenshots that imply a scenario passed when it has not been executed.

Binary screenshots will be added after the local and CI test suites are executed and verified.
